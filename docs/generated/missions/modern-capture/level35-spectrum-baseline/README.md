## Coverage boundary

The V4 preset intentionally produced Find Item, Find Person, and Return Item.
Repair and Kill Person require the same one-request-per-Difficulty-position
centered supplement used for level 25. Until that 11-request supplement is
captured, this is a complete item-focused baseline but not a five-type baseline.
