## Coverage boundary

The V4 preset intentionally produced Find Item, Find Person, and Return Item.
Repair and Kill Person did not occur in this level-25 session. The capture is a
complete 250-request-per-QL V4 item-focused baseline, but it is not by itself a
five-mission-type baseline.
