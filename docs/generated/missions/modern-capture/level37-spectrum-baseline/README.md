## Coverage boundary

The V4 preset intentionally produced Find Item, Find Person, and Return Item.
Repair and Kill Person require one centered-slider request at each Difficulty
position. Until that 11-request supplement is captured, this is a complete
item-focused baseline but not a five-type baseline.
