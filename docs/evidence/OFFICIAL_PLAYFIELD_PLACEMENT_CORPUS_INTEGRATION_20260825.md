The normalized 630-shard cohort is 73,264,965 bytes versus 86,019,468 bytes for
the source shards. Normalization preserved every independent record while
dropping source-only repetition, not evidence. The complete generated cohort is
76,104,779 bytes.

`OfficialSpawnRecordId` is the stable evidence identity:

```text
<SourceBuild>:1000014:<PlayfieldId>:district-<index>:record-<ordinal>
```

It is not an AO runtime dynel identity and is not called `NpcId`. Original
`ResourceInstance` is retained while normalized `PlayfieldId` is derived only
under the proven 630/630 instance-control relationship.

Every record retains placement, level/radius/rotation, timing, assistance,
flags, serialized size, offsets, packed-tag text/wire/native representations,
parse status, unknown/optional evidence, runtime-governance fields, and nullable
future mob-template join fields. Absent or unenumerated data remains null rather
than zero. Outside the exact PF4582 bridge, current runtime state is null and
runtime activation authorization is false.

`ACGHash_t` is modeled only as an official packed four-byte scalar/tag. It is
not classified as a cryptographic hash, `MonsterData`, resource identity,
dynel identity, or proven mob-template identity.
