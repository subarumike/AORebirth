# AORebirth GM Commands

Enter these commands in **vicinity chat**, including the leading dot.
Replace values in `<angle brackets>`; values in `[square brackets]` are optional.

## Teleport

- `.tp <x> <z> <playfieldId>` — Teleport the selected player, or yourself, keeping their current height.
- `.tp <x> <y> <z> <playfieldId>` — Teleport the selected player, or yourself, to exact coordinates.
- `.tp to <character name>` — Teleport yourself to an online player.
- `.tp summon <character name>` — Bring an online player to you.

## Spawn and despawn

- `.spawn <hash> <level>` — Spawn an NPC or supported static object from a known template at your location.
- `.despawn` — Remove the selected non-player target as if it died.

## Character stats and inspection

- `.set <statName|statId> <value>` — Change a stat on the selected character, or yourself.
- `.get stat <statName|statId>` — Show one stat.
- `.get stats` — Show character stats.
- `.get buffs` — Show active buffs.
- `.get quests` — Show active quests.
- `.get weapons` — Show weapon information.

## Give items, buffs, quests and setups

- `.give item <lowId> <highId> <ql>` — Give an item to the selected player, or yourself.
- `.give item <hash> <ql>` — Give an item using its template hash.
- `.give buff <nanoId>` — Immediately apply a buff to the selected character, or yourself. Does not teach the nano.
- `.give quest <hash>` — Grant a quest to the selected player, or yourself.
- `.give setup <aosetups URL>` — Import a setup onto yourself, replacing worn equipment and skills.

## NPC inspection

- `.npc source` — Show the selected NPC's content source.
- `.npc template` — Show template information.
- `.npc loot` — Show loot information.
- `.npc loot roll [count]` — Simulate 1 to 10,000 loot rolls. Creates no items.
- `.npc equipment` — Show equipment.
- `.npc nanos` — Show nanos.
- `.npc position` — Show location.
- `.npc respawn` — Despawn selected NPC and respawn it at its location

## Quest inspection

- `.quests` — List the selected player's active quests, or your own.
- `.quests info <questId> [characterId]` — Show quest details, optionally for a specific character.
- `.quests tp <questId>` — Teleport yourself to the quest's dungeon entrance.

## Mission chests

- `.chest roll <1-10000>` — Simulate mission chest populations with the production RK allowlist and loot selector. Awards no items and allocates no item instances; shows at most 100 distinct results.

## Game time

- `.gametime` — Show the game clock and how far it has been moved.
- `.gametime set <hh:mm[:ss]>` — Set the time of day (hours 0-26), keeping the day.
- `.gametime set <day> <hh:mm[:ss]>` — Set the day number and the time of day.
- `.gametime inc <n>[h|m|d]` — Move the clock forward (hours by default, decimals allowed).
- `.gametime dec <n>[h|m|d]` — Move the clock back.
- `.gametime reset` — Drop every move and return to the `Gameplay.json` worldClock.

## Weather

- `.weather <type|name> [intensity 0-100] [duration s] [radius m] [me]` — Start weather centred on you; `me` sends it to yourself only.
- `.weather list` — Show weather type numbers (0-7) and names.

## GM visibility

- `.visibility` — Show whether players can see you.
- `.visibility off` — Hide from players; anyone who sees you loses you.
- `.visibility on` — Be seen again.

## Account sanctions

The target is an account or character name; use `account:NAME` or `char:NAME` when a name is both.

- `.account info <target>` — Show the account, its status and its characters.
- `.account suspend <target> <duration> [reason]` — Suspend an account and remove its characters in play. Durations: s, m, h, d, w, combinable (e.g. `1d12h`), from 60 seconds to ten years.
- `.account ban <target> [reason]` — Ban an account permanently.
- `.account unban <target> [reason]` — Lift every active suspension and ban.
- `.account history <target>` — Show whether the account can log in, and its sanctions, newest first.

## Online players

- `.online` — List online players. GMs receive teleport links.

## Server performance

- `.serverstats [1|3|5|10|30]` — Show current-playfield performance over the chosen number of seconds.
- `.diag` — Show diagnostic help.
- `.diag on [sec]` — Start profiling, optionally for a set duration.
- `.diag off` — Stop profiling and keep the results.
- `.diag start [sec]` — Alias for `.diag on`.
- `.diag stop` — Alias for `.diag off`.
- `.diag reset` — Clear profiling results and the slow-tick log.
- `.diag top [n] [here|pfId]` — Show the top profiling entries.
- `.diag stages [here|all|pfId]` — Show profiling by stage.
- `.diag path [n] [here|pfId]` — Show path diagnostics.
- `.diag alloc [here|all|pfId]` — Show allocation diagnostics.
- `.diag pfs [1|3|5|10|30]` — Show playfield performance over the chosen number of seconds.
- `.diag slow` — Show slow-tick information.
- `.diag proc` — Show process information.
- `.diag threshold <ms|auto>` — Set the slow-tick threshold or use automatic selection.

## Debug messages

- `.debug` — Show debug controls.
- `.debug watchdog` — Toggle watchdog debug messages.
- `.debug watchdog on` — Enable watchdog debug messages.
- `.debug watchdog off` — Disable watchdog debug messages.

## Shutdown

- `.shutdown <seconds>` — Schedule engine shutdown.
- `.shutdown abort` — Cancel a scheduled shutdown.

## Required GM levels

- Most commands require **GM level 1**.
- `.online` is available to everyone (**GM level 0**).
- `.set` on another character requires **GM level 100**.
- `.set` cannot change `GmLevel`.
- `.visibility` and `.account` (`info`, `suspend`, `history`) require **GM level 100**.
- `.account ban` and `.account unban` require **GM level 1000**.
- `.shutdown` requires **GM level 1000**.
- These are the built-in levels. `Config/GmPermissions.json` (beside the GameData tree, else beside the process; loaded at startup) can override the level of any command by name, and of actions such as setting another character's stats.
