# AORebirth Captures

New AOSharp live captures are written here by the approved capture launcher.

Folder names put the useful location first and retain a compact unique capture ID last:

```text
ICC Shuttleport [PF 4582] - 20260818-143201
Subway [PF 127] - Geometry - 20260818-143201
```

The final timestamp remains the stable machine-facing capture ID used by analyzers and evidence references. Historical captures remain in their existing `tools-temp/AOSharpLiveCapture/bin/Debug/captures` paths; this workflow does not move or delete evidence.
